## 修改方案（最小化，仅改 1 个文件）

在 `uno.config.js` 的 `cssExtend` 对象中（第 15-38 行，现有 `code`、`li` 自定义样式的同一位置）添加一条 `img` 规则：

```js
const cssExtend = {
  // ...现有配置不动...

  img: {
    display: 'block',
    'margin-left': 'auto',
    'margin-right': 'auto',
  },
}
```

### 原理

- 所有 markdown 正文（文章页 `LayoutPost.astro`、关于页 `about.astro`）都渲染在 `.prose` 容器内，由 UnoCSS `presetTypography` 提供样式。预设目前只给 `img` 上下边距，不居中。
- `cssExtend` 与预设默认样式**按属性深合并**（已验证源码 `mergeDeep` 逻辑），因此：
  - 新增的 `margin-left/right: auto` 配合 `display: block` 实现水平居中；
  - 预设原有的 `margin-top/bottom`（上下 24px 间距）自动保留，不受影响。
- 对 markdown 的 `![](path)` 和裸 HTML `<img src>`（如《Pwn入门（一）》第 42 行的写法）均生效，因为最终都输出为普通 `<img>` 元素。

### 覆盖范围

- ✅ 文章正文图片（含 `.prose max-w-none`）
- ✅ 关于页图片
- ✅ 首页/列表页摘要中的图片
- ✅ 任意大小的图片（小图居中，大图本身占满宽度效果不变）
