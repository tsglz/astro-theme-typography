找工作感觉不会渗透测试差点意思，准备从 Pwn 入手赶紧恶补一下。

之前玩过一段时间的 Pwn，但是因为某些原因没有学下去（对被Windows恶意代码分析抓走了，老大快来救我喵~）

好了言归正传，先来讲一讲怎么配置环境。

因为我不是很需要图形化界面，这里使用的 WSL2 就直接命令行了。需要图形化自己网上找找教程就行了。

这里我用了 Ubuntu26.04 LTS，然后将权限直接提到了 root。因为我是配置完环境心血来潮写的博客，可能有些内容忽略了，见谅。

装好 Ubuntu 后输入 `sudo passwd root`，修改一下密码。

然后在 Ubuntu 中运行如下命令：

```shell
sudo tee /etc/wsl.conf <<EOF
[user]
default=root
EOF
```

然后以 root 权限登录 WSL2，并输入：

```shell
cp /home/你的用户名/.bashrc /root/.bashrc
source /root/.bashrc
```

退出后输入 `wsl --shutdown`

再次登录后即可看到命令行最前方出现 root 字样，对比如下：

<img src ="/Pwn/Pwn入门（一）/对比.png">

接下来换源：

备份一下：

```shell
sudo cp /etc/apt/sources.list.d/ubuntu.sources /etc/apt/sources.list.d/ubuntu.sources.bak
```

这里我用的清华源：

```shell
sudo sed -i 's|archive.ubuntu.com|mirrors.tuna.tsinghua.edu.cn|g; s|security.ubuntu.com|mirrors.tuna.tsinghua.edu.cn|g' /etc/apt/sources.list.d/ubuntu.sources
```

最后更新验证一下：

```shell
sudo apt update
```

差不多搞定了，接下来来装一些常用的妙妙小工具：

```shell
sudo apt install checksec
```

顺便一提，因为我已经是 root 权限了，所以其实不需要再使用 sudo，后续我将不再在命令中添加 sudo，如果没有提权，还是需要自己加上的~

然后来装 pwndbg，用官方的脚本不容易出错：

```shell
git clone https://github.com/pwndbg/pwndbg
cd pwndbg
./setup.sh
```

安装完成后进行测试：

```shell
gdb
```

看到如下内容即为安装成功：

```shell
------- tip of the day (disable with set show-tips off) -------
Use the pipe <cmd> | <prog> command to pass output of a GDB/Pwndbg command to a shell program, e.g. pipe elfsections | grep bss. This can also be shortened to: | <cmd> | <prog>
pwndbg>
```

对了，安装的时候注意 git clone 的路径，不确定怎么做就问问 ai，把你的配置告诉它就行。
